# Vim and Nvim
    - i - przeście w tryb insert
    - ESC - przeście tryb normalny
    - :w - zapisanie pliku
    - :q! - zamknięcie pliku
    - :wq - zapisanie i zamknięcie

    - 0 - początek lini
    - $ - koniec linie
    - gg - początek pliku
    - G - koniec pliku
    - :<nr> - skok do lini

    - x - usunięcie znaku pod kursorem
    - dd - wycięcie lini
    - yy - kopiowanie lini
    - p - wklejanie po kursorze
    - u - undo
    - Ctrl+r - redo

    - v - zaznaczenia znak po znaku
    - Ctrl+v - zaznaczanie lini
    - / - search
    - n - następny wynik search
